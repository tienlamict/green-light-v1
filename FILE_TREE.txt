KEY FILES EXPLAINED
===================

📄 app/layout.jsx
   - Root layout for entire app
   - Sets up Inter font from Google Fonts
   - Defines metadata (title, description)
   - Wraps all pages

📄 app/page.jsx
   - Main products page
   - Combines Header, Hero, Filters, Grid
   - Manages filter state
   - Mobile filter drawer logic

📄 app/globals.css
   - Tailwind @tailwind directives
   - Custom utility classes (.container-custom, .btn-primary)
   - Custom scrollbar styles
   - Global resets

📄 components/Header.jsx
   - Sticky header with shadow
   - Active menu state tracking
   - Mobile responsive menu
   - Cart badge counter

📄 components/Hero.jsx
   - Grey gradient background
   - 6 category icons with Lucide React icons
   - Responsive grid (3 cols mobile, 6 cols desktop)
   - Hover scale animations

📄 components/SidebarFilters.jsx
   - Collapsible sections with chevron icons
   - Interactive price slider
   - Color circle toggles
   - Tag chip toggles
   - Smooth transitions

📄 components/MobileFilterDrawer.jsx
   - Fixed position drawer
   - Backdrop with click-to-close
   - Slide-in animation
   - Only visible on mobile/tablet

📄 components/ProductCard.jsx
   - Next.js Image optimization
   - Hover state management
   - Favorite toggle functionality
   - Discount percentage calculation
   - Add to cart button with hover effect

📄 components/ProductGrid.jsx
   - Sorting logic (featured, price, name)
   - Grid/List view toggle
   - Responsive columns (1-4)
   - Pagination UI

📄 data/products.js
   - 16 product objects
   - Properties: id, name, price, originalPrice, image, category, discount
   - Uses placeholder images (placehold.co)
   - Easy to extend with more products
