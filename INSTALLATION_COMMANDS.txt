┌──────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                   │
└──────────────────────────────────────────────────────────────────┘

Port 3000 already in use?
  npm run dev -- -p 3001

Module not found errors?
  rm -rf node_modules package-lock.json
  npm install

Styles not loading?
  Clear browser cache and restart dev server
